# Bank Transaction Analysis System


### Система для анализа банковских транзакций с веб-интерфейсом, сервисами аналитики и автоматическими отчетами.

## 🚀 Возможности
## 🌐 Веб-страницы
* Главная страница - обзор карт, топ транзакций, курсы валют и акций

* Страница событий - анализ расходов и поступлений по категориям

## 🔧 Сервисы аналитики
* Выгодные категории кешбэка - анализ наиболее прибыльных категорий

* Инвесткопилка - расчет накоплений через округление трат

* Простой поиск - поиск транзакций по описанию и категориям

* Поиск по телефонам - автоматическое определение номеров телефонов

* Переводы физлицам - идентификация переводов физическим лицам

## 📊 Автоматические отчеты
* Траты по категории - анализ расходов за 3 месяца

* Траты по дням недели - средние расходы по дням

* Траты в рабочие/выходные - сравнение трат в разные типы дней

## 🛠 Технологии
* Python 3.13 - основной язык разработки

* pandas - обработка и анализ данных

* pytest - тестирование с 100% покрытием

* mypy - статическая типизация

* black/isort - автоматическое форматирование кода

* flake8 - проверка стиля кода

## 📦 Установка
### Требования

# 📊 Формат данных
## Входные данные (Excel)
* Дата операции - дата транзакции в формате DD.MM.YYYY HH:MM:SS

* Номер карты - последние 4 цифры номера карты

* Сумма операции - сумма в оригинальной валюте

* Сумма платежа - сумма в валюте счета

* Категория - категория транзакции

* Описание - описание операции

## Выходные данные (JSON)
Все функции возвращают данные в формате JSON для интеграции с веб-интерфейсом.
